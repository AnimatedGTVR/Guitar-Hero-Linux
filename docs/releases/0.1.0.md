# Guitar Hero Linux 0.1 Encore — First Set

This is the first playable GHL preview: a small, purpose-built Linux system that
opens its installer on first boot, then uses Backstage to hand the whole display
to Clone Hero.

## Included

- Backstage's bright Home Set interface: Wii-like channel cards, Switch-like
  horizontal focus and GHL's Play, Songs, Tools, and Power sections
- frame-rate-independent card, page, selection, dialog, and ambient animations
- first boot opens the guided installer; finishing or choosing Exit continues
  into Backstage, while interrupted setup returns on the next boot
- automatic aspect-correct scaling for 4:3, 16:9, 16:10, ultrawide, HiDPI,
  and portrait displays, with live resize handling
- keyboard, mouse, game-controller, and raw joystick navigation
- official Clone Hero Linux downloader, checksum verification, and EULA gate
- reliable fullscreen game handoff in QEMU through the compatible Xorg path
- ALSA audio, evdev input, DHCP networking, Git, Curl, Nano, and Fastfetch
- `ampkg` packages and a keyboard-driven TUI installer with safe target,
  profile, verification, BIOS GRUB, and removable-path UEFI GRUB flows
- minimal Desktop Mode for file and terminal work
- `ghl status`, `ghl doctor`, and `ghl logs` recovery commands
- stable UUID/LABEL root discovery for systems installed to real disks
- a release gate that checks ampkg, source warnings, the initramfs, the package
  database, and the packed ext4 filesystem before assembling the release

## Backstage controls

- Left/Right: change channel
- Up/Down: choose an item
- Left stick or WASD/HJKL: alternate navigation
- Enter, Space, or controller A: select
- Escape or controller B: back / return to the terminal
- Mouse: point and click; right-click goes back

## Boot the release kit

Run `scripts/run-root.sh` from the extracted release directory. It uses KVM when
available and falls back to software virtualization. Use
`scripts/run-root.sh --console` for a serial-terminal-only recovery boot.
Run `./verify.sh` once after extracting the kit to verify every boot artifact.
The downloadable artifact is `ghl-0.1.0-x86_64-first-set.tar.zst`; verify its
adjacent `.sha256` file before extracting it.

Clone Hero is third-party software and is not silently downloaded by the normal
GHL build. If the payload is absent, choose **Install / Repair Game** in
Backstage or run `clonehero install`, read the EULA, and confirm the download.
Personal rebuilds automatically retain a locally supplied payload; public
artifacts should be built with `BUNDLE_CLONEHERO=0`.

## Known limits

- QEMU currently uses software GL for the most dependable Unity/Xorg path.
- Physical HDMI, GPU, audio, and guitar-adapter validation is still hardware-specific.
- The installer formats existing partitions but deliberately does not invent a
  partition layout; BIOS and UEFI bootloader installation are guided steps.
- Backstage and Desktop Mode are functional early interfaces, not general-purpose desktop environments.
- `ghl.iso` remains recovery media; the complete 0.1 graphical system ships in
  the First Set QEMU release kit.
