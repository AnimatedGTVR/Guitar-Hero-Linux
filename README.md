# Guitar Hero Linux

Guitar Hero Linux (GHL) is a tiny Linux distribution built for one very specific and very stupidly cool purpose:

1. Buy a PS2 Gibson Guitar Hero guitar.
2. Mod it for Clone Hero.
3. Make it look like the Cinderstring from Roblox's *Fisch*.
4. Put a mini PC inside the guitar.
5. Install GHL and Clone Hero.
6. Plug the guitar into a display.
7. Play Clone Hero.

That's it.

The goal of GHL is to be an extremely small, purpose-built Linux system that boots directly into Clone Hero without needing a normal desktop environment.

## The Idea

Instead of connecting a Guitar Hero controller to a PC...

**the Guitar Hero controller is the PC.**

GHL is being built from scratch with a minimal userspace, inspired by lightweight distributions such as Tiny Core Linux.

## Status

🚧 **Very early development.**

Right now this is mostly an idea and an experiment. Expect things to break, change, or be completely rewritten.
